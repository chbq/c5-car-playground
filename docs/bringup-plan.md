## 阶段 5：PS2/SWD 双模式

状态：PS2 模拟通信、KEY1、LED、dead-man 和架空三轴运动通过；无线失联与 SWD 重连待补。

- 上电保留 SWD，PS2 引脚不驱动
- 测量 KEY1 极性和 PA8 连通性
- 断开 ST-LINK 后长按 KEY1，切换 PA12–PA15 至 PS2
- 验证有效中位帧解锁、L1/R1 dead-man 和三轴映射
- 验证 KEY1、松手、坏帧和断联停车
- 退出或复位后重新连接 SWD

电机动作测试仍须架空、低速、限时；PS2 详细设计见
[ps2-control.md](ps2-control.md)。

## 阶段 6：香橙派 HOST 链路

状态：USB/CH340、协议、架空三轴/斜移和进程强杀停车通过；模式互斥待补。

- Orange Pi USB-A ↔ 核心板 CH340 ↔ STM32 USART1，115200、8N1；
- 固定 11 字节 CRC8 命令/状态协议；
- 显式 ARM、20 Hz TWIST、150 ms 动作保持、200 ms 断联停车；
- USART1 逐字节中断接收，主循环执行命令并回报；
- HOST/PS2 互斥，STOP 全局有效，退出 PS2 后重新 ARM；
- 香橙派 MotionLink、默认 QUERY 的限幅 CLI、端口锁和只读环境检查。

实物顺序：SSH 环境检查 → CH340 枚举/权限 → DTR/RTS 重复开关检查 → 明确授权后
烧录 → STM32 QUERY/ARM/STOP → 架空低速三轴、STOP、断联停车和模式互斥。详见
[host-link.md](host-link.md)。

`brltty-udev.service` 已 mask，重启后 CH340、doctor 和 QUERY 通过。

## 阶段 7A：球心像素转向

状态：软件、板端、架空及 15/30 秒下地闭环通过。

- 只使用足球水平中心生成 `wz`，`vx/vy=0`；
- 默认干运行；只有显式 `--execute` 才能 ARM；
- 20 Hz、三周期确认、中央死区、限幅和 0.5 秒丢球停车；
- 先确认画面左右和转向符号，再架空验证，最后才考虑落地。

详见 [ball-yaw-control.md](ball-yaw-control.md)。

## 阶段 7B：球心像素横移

状态：软件、板端及修正方向后的 30 秒下地闭环通过。

- 球的水平误差只生成 `vy`，固定 `vx/wz=0`；
- 默认 `vy=250..800`，保留协议余量；
- 默认 dry-run，显式 `--execute` 才能 ARM；
- 先做带球 dry-run，再验证左右横移、中央停车、丢球恢复和到时 STOP。

详见 [ball-strafe-control.md](ball-strafe-control.md)。

状态：相机三轴映射、CSV 和 30 秒实车通过。

详见 [ball-follow-control.md](ball-follow-control.md)。
