# 香橙派服务部署

`autostart.sh` 管理 `c5-goalkeeper.service`。服务面向无 WiFi 测试场，固定运行：

```bash
main.py --headless --mode goalkeeper-test --dry-run-duration 7200
```

它自动打开相机/RKNN并记录守门员 dry-run CSV，但不打开 MotionLink、不 ARM、不控制
底盘，也不打开推板串口。服务不依赖图形桌面或网络。

## 前提

- 仓库位于不含空格/特殊字符的路径，例如 `/home/orangepi/c5-car-playground`；
- `yolov8` conda 环境或系统 Python 已装运行依赖；
- `main.py` 配置的 RKNN 模型存在；
- 相机最终枚举为 `/dev/video0`；启动前检查最多等待 30 秒；
- 无需连接核心板 CH340 或推板串口。

进入无 WiFi 场地前，先经 SSH 手工运行 `python3 doctor.py` 和一次
`python3 main.py --headless --mode goalkeeper-test`，确认模型、相机和日志目录。

## 安装与管理

```bash
chmod +x autostart.sh
./autostart.sh install
./autostart.sh status
```

常用命令：

| 命令 | 作用 |
|---|---|
| `on` / `off` | 开启/关闭下次开机自启 |
| `start` / `stop` | 启动/停止当前服务 |
| `restart` | 重启服务以加载新代码 |
| `log` | 跟踪 `c5-goalkeeper` journal |
| `uninstall` | 停止并移除服务 |

安装脚本按当前仓库路径和 Python 路径生成
`/etc/systemd/system/c5-goalkeeper.service`，并固定保留 headless dry-run 参数。服务在
`multi-user.target` 启动，不等待 WiFi 或桌面。模型缺失立即失败；相机未出现则等待
30 秒。故障退出 5 秒后重试，120 秒内失败 5 次后停止；正常退出不重启。

每次启动在 `logs/` 新建 `goalkeeper-<时间>-<运行标识>.csv`，即使离线墙钟重复也不
覆盖旧文件；控制台输出进入 systemd journal。
无网络时服务仍持续运行，之后恢复热点/网线再读取 CSV 和 journal。当前没有物理
“服务就绪”指示灯，不能仅凭开机时间认定推理已经正常。为防止离线持续写满磁盘，
服务运行 7200 秒后正常退出且不会自动重启；下次开机重新开始。

## 串口独占

当前服务不打开底盘和推板串口。若以后切换到其他会打开 MotionLink 的模式，使用 CLI
前仍应先停止服务：

```bash
./autostart.sh stop
python3 motion_cli.py       # 默认 QUERY
```

CLI 动作测试必须架空轮组并获得明确授权。完成后再 `./autostart.sh start`。

## 无 WiFi 操作顺序

1. 有网络时完成安装，执行 `status` 和一次人工 `start/stop`；
2. 断网重启一次，恢复网络后确认 journal 与 CSV，作为离线启动验收；
3. 测试场开机后只进行视觉记录，不因服务自启动而允许底盘或推板运动；
4. 测试结束优先正常关机。不要把直接断电当作常规停止方式，以免损坏日志或文件系统。

任何实车自动 ARM 都应使用另一套明确命名、带物理使能门槛的服务；不得向本 dry-run
unit 追加 `--execute` 或 `--continuous`。

## 独立运动服务

`c5-goalkeeper-motion.service` 是可选运动版，与 dry-run 服务互斥。安装默认执行：

- 不启用服务；
- 删除运动使能文件；
- 不启动、不 ARM、不发送运动命令。

冷启动预检会等待 `/dev/video0` 和唯一 C5 CH340 最多各 30 秒；无需网络。只有一只
CH340 时允许更换 Orange Pi USB 口，多只时必须设置 `C5_HOST_PORT`，不会猜测。任一
设备缺失时本次启动失败且不自动重试，避免设备或接线异常后反复 ARM。

```bash
chmod +x motion_autostart.sh
./motion_autostart.sh install
./motion_autostart.sh status
```

运动版固定运行 180 秒 `fast-lateral`：横移、前后、转向上限分别为
`650/100/250`，总预算 1000。没有可靠绝对定位，因此前后分量刻意最低；对方球门
丢失时立即 STOP，而不是继续搜索或追球。推板仍不执行。

只有完成架空、串口别名和方向检查后，才能显式允许下次开机自动运动：

```bash
./motion_autostart.sh enable-next-boot I_ACCEPT_AUTONOMOUS_MOTION
```

该命令要求能自动解析唯一 CH340 或已设置 `C5_HOST_PORT`，关闭 dry-run 自启，创建
`/etc/c5-goalkeeper-motion.enable` 并启用运动服务，但不会立即启动。撤销授权并停车：

```bash
./motion_autostart.sh disable-now
```

不得在车轮着地、场地无人监护或紧急断电不可用时首次启用。当前软件实现和假链路
测试不等于实车运动验收。
