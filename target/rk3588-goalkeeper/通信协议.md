# C5 HOST 串口协议

链路为 USART、115200、8N1，命令和状态均为固定 11 字节。多字节整数为小端序。

## 命令帧

```text
A5 5A TYPE SEQ VX_L VX_H VY_L VY_H WZ_L WZ_H CRC8
```

| TYPE | 命令 | 载荷与行为 |
|---:|---|---|
| `01` | ARM | 三轴必须为 0；停车后解锁 HOST |
| `02` | TWIST | 三轴 `int16_t`，各自范围 `[-1000,1000]` |
| `03` | STOP | 三轴必须为 0；任何模式均停车并解除控制状态 |
| `04` | QUERY | 三轴必须为 0；只查询状态 |

坐标沿用 C5：`vx>0` 前进，`vy>0` 右移，`wz>0` 俯视顺时针。上位机以 20 Hz 刷新 TWIST；每条运动保持 150 ms，STM32 连续 200 ms 未收到合法 HOST 命令则停车并解除 ARM。零 TWIST 停车但保持 ARM。

## 状态帧

```text
A5 5A 80 ACK_SEQ RESULT MODE HOST_STATE MOTION_STATE ERR_L ERR_H CRC8
```

每个完整候选帧都有一条状态回报。`ACK_SEQ` 回显命令序号；解析不到可靠序号的 UART/队列错误使用最近可用序号。

| 字段 | 值 |
|---|---|
| RESULT | `0 OK`、`1 BAD_CRC`、`2 BAD_TYPE`、`3 BAD_PAYLOAD`、`4 MODE_DENIED`、`5 NOT_ARMED`、`6 MOTION_FAULT`、`7 RX_OVERFLOW`、`8 UART_ERROR` |
| MODE | `0 HOST`、`1 PS2` |
| HOST_STATE | `0 DISARMED`、`1 ARMED` |
| MOTION_STATE | `0 UNINITIALIZED`、`1 STOPPED`、`2 MOVING`、`3 FAULT` |
| ERR | 饱和累计的协议/UART/队列错误数，`uint16_t` 小端 |

PS2 模式拒绝 ARM/TWIST，QUERY 仍可用；STOP 始终有效。退出 PS2 后必须重新 ARM。

## CRC8

CRC-8/ATM：poly `0x07`、init `0x00`、refin/refout false、xorout `0x00`，无查表实现，覆盖 Byte2–Byte9。

黄金向量：

```text
ARM seq=0x10:
A5 5A 01 10 00 00 00 00 00 00 C0

TWIST seq=0x22, vx=100, vy=-200, wz=50:
A5 5A 02 22 64 00 38 FF 32 00 36

OK status for ARM seq=0x10, HOST/ARMED/STOPPED/errors=0:
A5 5A 80 10 00 00 01 01 00 00 11
```

## 会话顺序

1. `QUERY` 确认接线、模式和状态；
2. `ARM` 收到 `OK + HOST + ARMED` 后才允许非零 TWIST；
3. 以 20 Hz 发送 TWIST 并逐帧核对 ACK；
4. 正常退出、异常退出或控制权切换时发送 STOP；
5. ACK/状态超过 200 ms 未更新时，上位机进入链路故障并要求重新 ARM。
