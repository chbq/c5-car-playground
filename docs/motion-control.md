# C5 运动控制

## 当前方案

四个新轮电机为 M370 闭环减速电机，使用各自的 TTL 插件和一块九路并联转接板。
STM32 通过 USART3 PB10/PB11 和底板同步串口驱动同一条 115200、8N1 TTL 总线；USART2 PA2/PA3 保留。
XS 二代闭环步进推板电机计划复用同一组 TTL T/R/GND；轮组和推板使用不同地址，动力供电另行核对。

M370 已通过 WCH-Link 直连完成四轮公共总线、逐轮正向、四轮同步前后和右横移架空验收；
烧录后 STM32 USART3 与 PS2 遥控运动链路也已通过。左横移、旋转和断联停车仍需单独验收。

## M370 协议

- 默认校验字节：`0x6B`。
- 地址：`1..255`，`0` 为广播地址。
- 速度命令：`Addr F6 Dir AccH AccL SpeedH SpeedL Sync 6B`；速度单位为 0.1 RPM。
- 单机立即停车：`Addr FE 98 00 6B`；固件用一个 `AA` 帧封装四条定址停车，避免地址 0 广播造成多台 TTL 同时回复。
- 四轮速度使用一个 `AA` 多电机帧，内含四条完整 `F6` 子命令，避免四条独立帧之间的启动偏差。
- 当前软件映射 `[-1000,1000]` 到 `[-300,300] RPM`，加速度为 `300 RPM/s`。
- 实物减速比为10:1。四台 M370 的 `GearRat` 原为默认1.00，现已写入10.00并完成掉电重启读取确认。速度命令现表示减速后输出轴转速，当前满杆上限为300 RPM，首次复测须架空并从小摇杆量开始。

轮地址已通过 WCH-Link/COM11 逐台确认为 1/2/3/4，对应 LF/RF/LR/RR；右前、左后、右后
分别改为 2/3/4 并完成掉电保存复查。115200、固定 `0x6B` 通信、公共总线和 STM32/PS2 运动链路均已实测；TTL 空闲高电平尚未测量。

## 坐标与轮速

- `vx > 0`：前进
- `vy > 0`：右移
- `wz > 0`：俯视顺时针

```text
LF = vx + vy + wz
RF = vx - vy - wz
LR = vx - vy + wz
RR = vx + vy - wz
```

安装极性 `+ - + -` 已通过四轮逐一正向和整组前后架空验证。超限时四轮同比缩放。

## 软件分层与安全

| 层 | 职责 |
|---|---|
| `c5_motor_protocol` | M370 停车帧、速度子帧和 AA 四轮帧编码 |
| `c5_mecanum` | `vx/vy/wz` 转 LF/RF/LR/RR 并归一化 |
| `c5_motion` | 运动 API、限时停车、故障锁存 |
| `c5_motor_bus_hal` | USART3 阻塞式发送 |
| `c5_control` | HOST/PS2 仲裁、显式 ARM 与失联停车 |

上电只请求四轮停车，不自动运动。非零动作必须带 1–1000 ms 保持时间并持续刷新；到期发送四轮定址停车组合帧。
发送失败会锁存 `C5_MOTION_FAULT` 并每 100 ms 重试停车。M370 手册未给出可替代这一策略的电机侧心跳看门狗，因此 MCU 卡死或掉电后的保持行为仍需架空实测。

PS2 在安全键仍按住、三轴摇杆回中时发送四条 `F6` 零速命令，以 600 RPM/s 减速，并进入 `DECELERATING`；550 ms 后补发四轮定址 `FE`，保证停车有界。安全键松开、无效/超时帧、KEY1、模式切换和运动故障仍立即发送 `FE`。该策略已完成软件测试和 AC5 构建，尚未烧录和实车验收。

## Emm42 推板电机（待接入）

用户确认推板为 Emm42，屏幕为 `CR_VFOC`、`MotType=1.8`、16 细分。X42S V1.0.5 手册和厂商 STM32F103 Emm V5 例程使用 115200、8N1。位置帧为 `Addr FD Dir VelH VelL Acc Pulses[4] Raf Sync 6B`，立即停止为 `Addr FE 98 Sync 6B`；不能使用 X 固件的角度位置帧。推板将使用单独定址帧，不加入只含轮组 ID 1–4 的 `AA` 帧。

推板原为 ID 2，已通过 WCH-Link/COM11 持久化改为 ID 5；掉电重启后 ID 5 查询正常、旧 ID 2 无应答。STM32 只接共享 TTL TX/RX/GND，不接限位 GPIO。用户观察收回端约 -0.6 度、推出端约 186.0 度；串口在收回端读到负向 115 个编码器计数，按 65536 计数/圈约为 -0.632 度，与屏幕一致。两端是机械硬挡，没有电气限位信号。当前回零参数为模式 0、方向 0、30 RPM、10 s 超时；不启用日常碰撞回零。初始软件工作区拟设为约 5–180 度，在两端保留约 5–6 度余量；数值须经低速实物验收后才能确认。

多次有界测试中，`F3`、`F6`、`FD`、`FE` 均返回成功，但转速和位置不变，轴没有保持力；状态字却报告已使能。脉冲端口已设为 `PUL_OFF` 并掉电保持，母线约 11.9 V，停止后相电流仅 4-7。原版手册确认面板没有点动功能，且 `0x19` 对应 1.8 度电机。推板固件接入在查明实际无力矩原因前暂停，不提高电流、速度或行程。

接线和首次动作顺序见 [M370 TTL 接线与调通](m370-bringup.md)。
