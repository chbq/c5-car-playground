# 当前任务：M370 四轮优化与 XS 推板接入

状态：M370 四轮运动链路已恢复，正常回中软停车完成软件验证；Emm42 无实际力矩，接入暂停排障

## 目标

用一条共享 TTL UART 总线连接四个 M370 轮电机和一个 XS 二代闭环步进推板电机，恢复底盘运动并补充推板伸出/收回功能。

## 实物边界

- 不接 RS485 A/B；当前核心板没有板载 RS485 收发器。
- 新 TTL 线接底板同步串口的 USART3 TX/RX/GND；USART2 不使用。
- 地址、公共总线、WCH-Link 直连运动和 STM32/PS2 运动链路已实测。
- 实物减速比为10:1；四台电机内部 `GearRat=10.00` 已完成掉电保持确认。
- 当前固件满杆为300 RPM输出轴，约为校准前实际车轮速度的10倍；必须先架空、小摇杆复测。
- 用户实测速度可接受；新软停车策略尚未烧录和实车验收。
- XS 推板复用同一组 USART3 TTL T/R/GND 是用户接受的设计输入；其动力供电不得从该结论推断。
- XS 脉冲端口已设为 `PUL_OFF` 并掉电保持；`CR_VFOC`、`MotType=1.8`、16 细分已核对。原版手册没有面板点动功能。
