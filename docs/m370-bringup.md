# M370 TTL 接线与调通

## 结论

图中的九路板是并联接线/供电板。顶部 8P 端子的复用标注表示：TTL 模式使用 `T/B/L` 的
`T`（电机 TX）和 `R/A/H` 的 `R`（电机 RX）；A/B 与 H/L 分别留给 RS485/CAN。
本车使用 TTL，不安装或外接 RS485 收发器。

这里的“单总线”指四个电机共用一组 UART TX/RX/GND，并不是只有一根信号线。

## 断电接线表

| 底板同步串口 TB2 | MCU | 九路板顶部 | 方向 |
|---|---|---|---|
| 3 / TXD | PB10 / USART3_TX | `R/A/H` | STM32 TX → 电机 RX |
| 2 / RXD | PB11 / USART3_RX | `T/B/L` | STM32 RX ← 电机 TX |
| 4 / GND | GND | `Gnd` | 共地 |

- 四个 M370 的 8P 原装线分别插入任意四个并联口；轮位由地址决定，端口号不决定轮位。
- 电机动力接九路板“电源输入口”或 `V+`/`Gnd`，按 M370 额定输入范围供电。
- 不把 STM32 的 3.3 V、5 V 接到九路板 `V+`，也不要同时从两个电源口反向供电。
- TTL 串行模式下，顶部 `Dir`、`Stp`、`En`、`Com` 不接 STM32。
- 同步串口的 1 / KEY1 和 5 / 5 V 不接九路板；USART2 PA2/PA3 不使用。

首次通电前，先用万用表确认 V+/GND 极性和电压；再确认 `T/B/L` 空闲电平不会超出 STM32 PA3 输入允许值。

## 逐台设址

四台电机不能以相同地址直接并到 TTL 回线上。只连接一台电机，依次完成：

1. 设串口功能为 `P_Serial=UART_FUN`，115200、8N1、校验字节 `0x6B`；
2. 关闭周期主动上报；
3. 设置地址：左前 1、右前 2、左后 3、右后 4；
4. 断电重启并按新地址查询确认；
5. 断电后再接下一台。

具体菜单/上位机操作以随电机提供的 M370 工具和手册为准。地址全部唯一后，才把四台插入九路板。

## 首次架空动作

1. 抬起并固定底盘，轮周无人，保留可立即断开的动力开关。
2. 先给电机板供电，再给 STM32 上电；确认没有自行转动。
3. 烧录前运行 `tools/verify.ps1`；烧录仍需显式确认开关。
4. 先执行 HOST `query` 和 `stop`，确认 STM32 为 `DISARMED/STOPPED`。
5. 每次只测一个小动作：

```powershell
python .\target\rk3588-goalkeeper\motion_cli.py query
python .\target\rk3588-goalkeeper\motion_cli.py stop
python .\target\rk3588-goalkeeper\motion_cli.py move --vx 50 --duration 0.2 --execute
```

6. 若任一轮方向错误，先停车断电，只修改 `c5_motion_config.h` 中对应轮的符号；不要交换地址来掩盖轮位错误。
7. 逐轮确认 1–4、前进方向和停车后，再测 `vy=50`、`wz=50`；最后测试停止刷新后的自动停车。

当前代码的 `vx=50` 约对应满量程的 5%，即约 15 RPM。若静摩擦导致不转，可在架空状态逐步增加到 100；不直接使用满量程。
