# 香橙派服务部署

`autostart.sh` 管理 `c5-goalkeeper.service`。服务运行 `main.py`，当前只显示推理和链路状态，不会自动 ARM 或动车。

## 前提

- 仓库位于不含空格/特殊字符的路径，例如 `/home/orangepi/c5-car-playground`；
- `yolov8` conda 环境或系统 Python 已装运行依赖；
- `main.py` 配置的 RKNN 模型存在；
- `/dev/ttyS7` 已启用且运行用户有读写权限；
- 需要 OpenCV 窗口时，桌面已自动登录并设置 `DISPLAY=:0`。

先经 SSH 手工运行 `python3 doctor.py` 和 `python3 main.py`。只有确需桌面窗口时才配置 NoMachine。

## 安装与管理

```bash
chmod +x autostart.sh
./autostart.sh install
./autostart.sh status
```

常用命令：

| 命令 | 作用 |
|---|---|
| `on` / `off` | 开启/关闭下次开机自启 |
| `start` / `stop` | 启动/停止当前服务 |
| `restart` | 重启服务以加载新代码 |
| `log` | 跟踪 `c5-goalkeeper` journal |
| `uninstall` | 停止并移除服务 |

安装脚本按当前仓库路径和 Python 路径生成 `/etc/systemd/system/c5-goalkeeper.service`。故障退出 5 秒后重试，120 秒内失败 5 次后停止；正常退出不重启。程序关闭时会尽力发送 STOP。

## 串口独占

`main.py`、systemd 服务和 `motion_cli.py` 共用端口锁。使用 CLI 前先执行：

```bash
./autostart.sh stop
python3 motion_cli.py       # 默认 QUERY
```

CLI 动作测试必须架空轮组并获得明确授权。完成后再 `./autostart.sh start`。
