## 已确认协议

厂商根目录说明默认使用 Emm 固件。用户手册 V1.0.5 与树莓派示例一致：

| 项目 | 默认值/格式 |
|---|---|
| 串口 | 115200、8N1 |
| 电机地址 | `0x01`；`0x00` 为广播 |
| 自由协议校验 | 帧尾固定 `0x6B` |
| 正确应答 | `地址 功能码 02 6B` |
| 参数/条件错误 | 返回数据 `E2` |
| 格式错误 | 返回数据 `EE` |
| 动作完成 | 配置允许时主动返回 `9F` |

第一版优先使用默认自由协议，不修改电机持久配置、不切换 MODBUS。关键 Emm 命令：

| 功能 | 主机发送 |
|---|---|
| 查询电机状态 | `01 3A 6B` |
| 使能锁轴 | `01 F3 AB 01 00 6B` |
| 取消使能/松轴 | `01 F3 AB 00 00 6B` |
| 速度模式 | `01 F6 DIR SPEED_H SPEED_L ACC 00 6B` |
| 相对当前位置位置模式 | `01 FD DIR SPEED_H SPEED_L ACC PULSE_BE32 02 00 6B` |
| 立即停止 | `01 FE 98 00 6B` |

`DIR=00/01` 分别为 CW/CCW；速度为 0-3000 RPM 的大端 `uint16`；脉冲数为大端
`uint32`。默认 1.8°电机、16 细分时 3200 脉冲一圈，但实物细分和机构行程必须读取
或测量，不能直接沿用。状态字 `bit0` 为使能、`bit1` 为到位、`bit2` 为堵转、
`bit3` 为堵转保护、`bit4/5` 为左右限位输入。

## 接线选择

驱动板通讯端子复用为 `R/A/H`、`T/B/L`，必须与实际插装通讯小板匹配：

- TTL：电机 `R` 接主机 TX，电机 `T` 接主机 RX，两端 GND 共地；
- RS485：电机 `A/B` 接收发器 `A/B`；
- 电机动力单独使用常规版 10-29 V、建议 12/24 V 且 3 A 以上，不能由 Orange Pi
  或 USB 串口适配器供电；禁止带电插拔动力、通讯和电机线。

用户手册画出了 3.3 V STM32 UART 直连 TTL 版，但没有给出完整输入阈值。车载第一版
优先建议 Orange Pi 加独立 USB-RS485；若实物为 TTL 小板，则使用明确为 3.3 V 逻辑的
独立 USB-TTL。不得把推板适配器误识别为底盘 CH340。

建议为两条链路建立稳定别名：

```text
/dev/c5-host    -> 核心板 CH340 / STM32 MotionLink
/dev/c5-pusher  -> ZDT 推板独立 USB 串口
```

## 第一版控制闭环

保持 `PusherIntent` 与串口适配解耦：

1. 启动只打开显式 `/dev/c5-pusher`，查询 `3A`，不自动使能；
2. 收到 `CYCLE` 后显式使能，以低速、小行程执行“伸出 → 到位 → 收回 → 到位”；
3. 到位优先轮询 `3A.bit1`，每段均有独立超时；不先修改主动 `9F` 应答配置；
4. 变为 `IDLE`、观测超时、串口异常或进程退出时发送 `FE` 立即停止；
5. 是否随后取消使能必须由机构安全决定，因为取消使能会松轴；
6. 堵转、堵转保护、限位异常、错误应答或超时进入故障，禁止自动继续往复。

实现顺序为纯编解码与假串口测试、USB 适配器只读查询、脱离机构低速测试、装机构短
行程测试，最后才允许守门策略触发。每一级均需单独授权，不能随底盘测试自动执行。

## 香橙派备用实现

当前实现保持独立，不接入 `main.py`：

| 模块 | 作用 |
|---|---|
| `zdt_pusher_protocol.py` | 固定 `0x6B` 帧、应答和状态字编解码 |
| `zdt_pusher_link.py` | 显式端口、独占锁、4 字节应答、超时和安全 STOP |
| `zdt_pusher_control.py` | 伸出/到位/收回/到位的受限往复及故障退出 |
| `pusher_cli.py` | 人工查询、STOP 和带 `--execute` 的有界往复入口 |

只读查询：

```bash
python3 pusher_cli.py --port /dev/c5-pusher query
```

`cycle` 不提供任何硬件参数默认值，必须显式给出行程、速度、加速度、伸出方向和空闲
行为；缺少 `--execute` 时甚至不会构造串口链路。备用 CLI 额外限制为最多 3200 脉冲、
300 RPM、10 次往复和每段 10 秒。即使软件允许，这些上限也不是实物安全值；首次
脱离机构测试仍应使用更小参数。

## 未决输入

- 实物电机/驱动板型号、固件版本和 TTL/RS485/CAN 通讯小板类型；
- 推板零位、最大安全行程、传动比、细分、CW/CCW 对应伸缩方向；
- 是否有机械限位或外部限位开关，以及限位有效电平；
- `IDLE` 和故障时应锁轴还是松轴；
- 推板往复速度、加速度、周期、最长连续工作时间和电源能力。
